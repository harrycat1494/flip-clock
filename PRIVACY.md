# Flip Clock: privacy

Flip Clock collects nothing.

- **No data leaves your PC.** The program has no network code. It never connects to the internet, sends nothing and receives nothing.
- **No account, no tracking, no ads, no analytics.**
- **What it stores, and where:** its own settings (place, size, colours, alarm time and the like) in one small file on your PC, `%APPDATA%\FlipClock\settings.json`. The Microsoft Store version keeps that file inside the app's own private storage.
- **Start with Windows:** only if you tick it. The downloaded program then adds one entry to your own user's start-up list; the Microsoft Store version uses the start-up switch that Windows provides for Store apps. Untick it and it is off again.
- **Sound:** with the flap sound or the alarm on, the clock plays through your normal sound output. It records nothing and uses no microphone.

The complete source code is public in this repository, so all of this can be checked.
